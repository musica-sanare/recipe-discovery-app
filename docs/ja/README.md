# Recipe Discovery ドキュメント

Recipe Discovery に関する文書をすべて並べた索引だ。プロダクトやコンテンツを確認する人は仕様とポリシーから、開発する人はアーキテクチャとローカル開発のガイドから読むとよい。最後の作業用ドキュメントは、開発中に使う英語のみの記録だ。

## 仕様と設計

| 文書 | 説明 |
|---|---|
| [プロダクト仕様](SPEC.md) | プロダクトの目的、ユーザー、MVP の範囲、フロー、入力、受け入れ基準 |
| [アーキテクチャ](ARCHITECTURE.md) | 技術的な構成、レイヤー、責務 |
| [UI 設計](UI_DESIGN.md) | 画面、ナビゲーション、状態、スタイル、メッセージカタログ |
| [栄養計算](NUTRITION_CALCULATION.md) | 栄養計算のルール、丸め、不確かさ |
| [コンテンツポリシー](CONTENT_POLICY.md) | レシピの作成、アレルゲン、食品安全、健康に関する表現、翻訳 |
| [データソース](DATA_SOURCES.md) | データソース、利用条件、出典表示、取り扱いのルール |

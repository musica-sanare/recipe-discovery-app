### 利用条件
- *検証済み*（https://www.mext.go.jp/a_menu/syokuhinseibun/index.htm）：食品成分のデータは自由に利用できます。論文、書籍、アプリケーションなどで二次利用する場合、文部科学省は出典を「日本食品標準成分表（八訂）増補2023年から引用（又は出典）」と記載するよう求めています。
- *検証済み*（https://fooddb.mext.go.jp/）：オンラインのデータベースは試験的なサービスで、その利用によって生じた損害について文部科学省は責任を負いません。このプロジェクトはオンラインのデータベースではなく、公開されているワークブックを使います。
- オーナーの立場（2026-10-18）：データは計算の基礎として使い、アプリの中で出典を示します。別途の問い合わせは予定していません。アプリでは、値がアプリ独自の計算であり、文部科学省が承認したものではないことも示します。
- 利用についての問い合わせ先（文部科学省のページより）：kagseis@mext.go.jp。

### 取り扱いのルール
- 元のワークブックは**決してコミットしません**。`data/raw/`（git で無視）またはリポジトリの外に置きます。
- スクリプトで、食品辞書が参照する食品番号と、アプリが使う列だけを抽出します。記号の印（`-`、`Tr`、`(0)`、`(Tr)`、`( )`）は保ちます。
- 抽出したサブセットとマニフェスト（取得元の URL、ワークブックの更新日、SHA-256、抽出スクリプトの版、抽出日）を Git で管理し、元のファイルがなくてもビルドを再現できるようにします。
- データソースの更新：新しいファイルをダウンロードし、マニフェストを更新し、抽出をやり直し、栄養値のスナップショットの差分を確認し、変更を [DECISIONS.md](../working/DECISIONS.md)（英語のみ）に記録します。

### 抽出（フェーズ 0 Stage 0.2 で実装）
- ワークブックは、`data/composition/manifest.json` の `rawFile` が示すパスに置きます（現在は `data/raw/mext/20260327-mxt_kagsei-mext-000029402_02.xlsx`。git で無視）。
- `npm run data:extract` は、SHA-256 をマニフェストと照合し、マニフェストにあるシート（`表全体`）を読み、`requestedCodes` に挙げた食品番号で `data/composition/foods.json` を書き出します。出力は決定論的です（食品番号順、タイムスタンプなし）。
- `node tools/extract-composition.ts --search <regex>` は、一致する食品番号と名前を一覧にし、番号を選ぶ助けにします。
- 列は位置ではなく、成分識別子の行と日本語の見出しで見つけます。抽出する識別子：`REFUSE`、`ENERC_KCAL`、`PROT-`、`PROTCAA`、`FAT-`、`FATNLEA`、`CHOAVLDF-`、`CHOCDF-`、`FIB-`、`NACL_EQ`（`shared/composition.ts`）。各値は記号の区分（`measured`、`zero`、`trace`、`estimated`、`estimated_zero`、`estimated_trace`、`unmeasured`）を保ちます。認識できないセルの内容があると、抽出は止まります。
- 食品名は公開されているとおり日本語だけを保ちます。3 つのロケールでの表示名は食品辞書に属します（Stage 0.4）。
- テストで、管理しているサブセットを、ワークブックなしでスキーマとマニフェストに照らして検証します。
- 出典表示の文言と表示場所：[CONTENT_POLICY.md](CONTENT_POLICY.md) §5。

### 調理の表（フェーズ 0 Stage 0.3 で実装）
- 表 12（重量変化率）、表 13（揚げ物）、表 14（油いため・ソテー）は説明の PDF にしかありません。PDF のテキスト層では表の列が入り乱れるため、必要な行は描画したページの画像から `data/composition/cooking.json` に**手で書き写して**います。各項目のページ番号と、PDF の SHA-256（`d1196cc8…f116`、ファイル `data/raw/mext/20260327-mxt_kagsei-mext-000029402_0001.pdf`、git で無視）も記録しています。
- `rawCode`（各調理後の食品と組になる生の食品）はこのプロジェクトが割り当てたものです。数値はすべて文部科学省のもので、印刷どおりに書き写しています（元データに既知の不整合が 1 つあります：食品 11290 は表 12 で 82 %、表 13 で 81 g）。
- 検証：
  1. `npm run data:verify-cooking`（macOS のみ。`tools/macos/pdf-page-text.swift` 経由で PDFKit を使用）は、書き写したすべての数値と食品番号が、PDF のテキスト層の該当ページにあることを確認します。弱点：テキスト層は列の順に並ぶため、同じページのほかの場所にも現れる数値は通ってしまいます。
  2. `test/node/cooking-data.test.ts` のテストは、PDF なしで毎回のチェックで実行されます：衣のない食品のたんぱく質の残存率（60〜115 %）、成分値から計算し直した表 13〜14 の脂質の変化（1 g 以内）、表 12 と表 13〜14 の調理後の質量の整合、衣を含む基準の変化率が主材料の変化率より低いこと。2026-10-18 に、わざと入れた書き写しの誤り（61 → 16、4.6 → 6.4）をこれらのテストが検出しました。
- 食品の追加：ページを描画し、その行をページ番号とともに書き写し、生と調理後の食品番号をマニフェストに追加し、`npm run data:extract`、`npm run data:verify-cooking`、テストを実行します。

### 既知の制限
- 八訂には公式の英語の食品名がありません。PDF（今後の課題の章）で *検証済み*：英語版や翻訳の機能は「検討中」とされています。2015 年版は日本語と英語で公開されました。その英語名と食品番号を参考にできるかは 要確認 です。
- 重量変化率（表 12）と揚げ物・いため物の脂質のデータ（表 13〜14）は PDF にあり、ワークブックにはありません。
- 目安量の表がありません。
